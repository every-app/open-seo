---
title: "Embed in another dashboard"
description: "Show a project's live rankings and Search Console data inside GoHighLevel or any dashboard that can embed a web page."
---

An embed link shows a page of your project, live and read-only, on another site, such as a client's GoHighLevel sub-account. Viewers don't need an OpenSEO account, and they can't change the project or spend credits.

## Get an embed link

1. Open **Project settings**, then **Integrations**.
2. In **Embed links**, turn on **Show this project in another dashboard**.
3. Pick a view and copy its link.

| View | What the link shows |
| --- | --- |
| Overview | Rankings and Search Console together |
| Rank Tracking | The rank tracking table, with a tracker picker |
| Search Console | Search Console queries and pages, once [Search Console is connected](/docs/google-integrations) |

Only workspace owners and admins can turn on embed links.

The switch covers every embed link in the project. Turning it off stops them all, and turning it on again makes new links. Links also stop working if the person who turned them on leaves your workspace.

Each project has its own links, so give each client their own project.

## Add it to GoHighLevel

**As a sidebar page:** in your agency's **Settings → Custom Menu Links**, create a link, paste the embed link, and set it to open as **Embedded Page (iFrame)**. Show it in the client's sub-account.

**As a dashboard tile:** in the client's sub-account, edit the **Dashboard**, add an **Embed** widget, choose **URL**, and paste the embed link.

## Self-hosting

Embed links need accounts, so they work on OpenSEO Cloud and on self-hosted installs with their own sign-in.
