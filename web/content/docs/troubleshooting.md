## Connecting an agent

- [ChatGPT](/docs/chatgpt#troubleshooting): the plugin isn't available, no Developer mode, OAuth errors, or tools that don't show up in a chat.
- [Claude](/docs/claude-code-plugin#troubleshooting): plugin skills that don't appear, `/reload-plugins` output, the plugin cache, and sign-in.
- [Codex](/docs/codex-plugin#troubleshooting): the server isn't found after install, sign-in errors, and CLI commands that changed between versions.
- [Any MCP client](/docs/mcp#troubleshooting): the server URL, failed authorization, and projects your agent can't find.

## Still stuck?

Email [support@openseo.so](mailto:support@openseo.so) with what you tried, the step that failed, and the error message. Don't include passwords, API keys, or sign-in codes.
