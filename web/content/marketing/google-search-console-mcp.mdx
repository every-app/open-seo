Most Google Search Console (GSC) MCP servers take a lot of effort to set up. You need to create a Google Cloud project, enable an API, build an OAuth client, download a `credentials.json`, then keep a local server running. SEOShark handles the Google connection for you. You sign up, connect your property, and start asking.

## Setup: no Google Cloud project

1. Sign up for SEOShark.
2. Go through the onboarding. When prompted, click **Connect Search Console** and pick your property.
3. Add the SEOShark MCP endpoint to your client (steps below) and approve the SEOShark login when prompted.

The hosted MCP server URL is:

```txt
https://app.seoshark.example/mcp
```

### Claude Code

```bash
claude mcp add --transport http --scope user seoshark https://app.seoshark.example/mcp
```

### Claude Desktop

1. Open Customize → Connectors.
2. Click **Add** (or **+**), then choose **Add custom connector**.
3. Paste `https://app.seoshark.example/mcp`.

### Cursor

1. Open Cursor Settings → Tools & Integrations → MCP Tools.
2. Click **New MCP Server** (this opens `mcp.json`) and add:

```json
{
  "mcpServers": {
    "seoshark": {
      "url": "https://app.seoshark.example/mcp"
    }
  }
}
```

### Codex CLI

```bash
codex mcp add seoshark --url https://app.seoshark.example/mcp
```

Any other MCP client works the same way: add `https://app.seoshark.example/mcp` as a remote server and sign in. Full setup and troubleshooting live in the [MCP docs](/docs/mcp).

### The DIY way (every other GSC MCP)

1. Create a Google Cloud project
2. Enable the Search Console API
3. Configure the OAuth consent screen
4. Create OAuth client credentials
5. Download `credentials.json`
6. Install and run a local MCP server

## What your agent can read

Two read-only tools over the property you connect. Both pull Google's own numbers, and neither uses credits.

**Search performance.** Clicks, impressions, CTR, and average position for your site, sliced by query, page, country, device, and date. Pull up to 16 months of history in a single question.

**URL inspection.** Whether a page is indexed and, if not, why: coverage status, last crawl, the canonical Google chose versus the one you declared, plus mobile and rich-result checks. Up to 10 URLs at a time.

The agent can read and inspect. It cannot change anything in your account.

## What it costs

They're included with your SEOShark plan, alongside the credit-based tools (keyword research, rank tracking, backlinks) that run through the same MCP endpoint. ## FAQ

### What does it cost?

The Search Console MCP tools are included with your SEOShark plan and use zero credits. SEOShark's other tools (keyword research, rank tracking, backlinks) use usage credits, through the same endpoint. See [pricing](/pricing).

### Can I self-host it?

Yes. You can [self-host](/docs/self-hosting) SEOShark, including the Search Console MCP. The one-click connection here uses SEOShark's hosted Google app. If you self-host, you bring your own Google OAuth client, the same Cloud-console step the hosted version saves you. Hosted means no setup; self-hosted means full control.

### Is it read-only?

Yes. SEOShark requests read-only access (`webmasters.readonly`). Your agent can read performance data and inspect URLs, but it can't change your account.

### Which AI clients work?

Any MCP client, including Claude Code, Claude Desktop, Cursor, Codex, and OpenClaw. Add the SEOShark MCP endpoint and sign in.

### How fresh is the data?

It's Google's own data, so the most recent few days can be incomplete. History runs back 16 months, the same as the Search Console interface.
