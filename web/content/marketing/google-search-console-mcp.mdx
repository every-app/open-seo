## Is there a Google Search Console MCP server?

There are several, all from other developers. As of November 2026, Google does not publish an official MCP server for Search Console. It does publish [one for Google Analytics](https://github.com/googleanalytics/google-analytics-mcp), which is why many people expect a Search Console one too.

You have two kinds of option:

- An open-source server you run yourself. These are free. You create a Google Cloud project, enable the Search Console API, make your own credentials, and keep the server running on your computer.
- A hosted server. The provider handles the Google connection, and you sign in with Google. OpenSEO is one of these.

### The open-source servers

These are the two that come up most often when people compare:

- [mcp-gsc](https://github.com/AminForou/mcp-gsc) is written in Python, MIT-licensed, and the most starred, with about 2,200 GitHub stars. It covers search analytics, URL inspection and sitemaps. You sign in with your own OAuth client or a service account. It is read-only unless you turn on the tools that add or remove properties and sitemaps.
- [mcp-server-gsc](https://github.com/ahonn/mcp-server-gsc) is written in TypeScript and MIT-licensed. It focuses on search analytics, with up to 25,000 rows per request and regex filters. It signs in with a service account that you add to your property.

Both are good if you are comfortable in the Google Cloud console and only need Search Console data. Both need a Google Cloud project.

### Where OpenSEO fits

OpenSEO's Search Console MCP is hosted, so there is no Google Cloud project to create. You sign up, connect your property, and start asking. It is read-only: your agent can read performance data and inspect URLs, and it can't change anything in your account. The same connection also gives your agent keyword research, rank tracking and backlink data, which Search Console doesn't have. It costs $10 a month, and the Search Console tools use no credits. OpenSEO is open source too, so you can [self-host it](/docs/self-hosting) with your own Google OAuth client.

### Claude

Add the [OpenSEO connector](https://claude.ai/directory/connectors/openseo) from Claude's directory and sign in. It works in Claude on the web, desktop and mobile. You can also open **Customize → Connectors** in Claude, search for OpenSEO, and select **Connect to Claude**.

### Cursor

1. Open Cursor Settings → Tools & Integrations → MCP Tools.
2. Click **New MCP Server** (this opens `mcp.json`) and add:

```json
{
  "mcpServers": {
    "openseo": {
      "url": "https://app.openseo.so/mcp"
    }
  }
}
```

### Codex CLI

```bash
codex mcp add openseo --url https://app.openseo.so/mcp
```

For ChatGPT web or desktop, follow the [ChatGPT setup steps and plan requirements](/docs/chatgpt). For other remote MCP clients, add `https://app.openseo.so/mcp` and sign in. Full setup and troubleshooting live in the [MCP docs](/docs/mcp).

### The DIY way (open-source GSC MCP servers)

1. Create a Google Cloud project
2. Enable the Search Console API
3. Configure the OAuth consent screen
4. Create OAuth client credentials
5. Download `credentials.json`
6. Install and run a local MCP server

## What your agent can read

Two read-only tools over the property you connect. Both pull Google's own numbers, and neither uses credits.

**Search performance.** Clicks, impressions, CTR, and average position for your site, sliced by query, page, country, device, and date. Pull up to 16 months of history in a single question.

**URL inspection.** Whether a page is indexed and, if not, why: coverage status, last crawl, the canonical Google chose versus the one you declared, plus mobile and rich-result checks. Up to 10 URLs at a time.

The agent can read and inspect. It cannot change anything in your account.

## FAQ

### What does it cost?

The Search Console MCP tools are included with the $10/month OpenSEO plan (which comes with a 30-day money-back guarantee) and use zero credits. OpenSEO's other tools (keyword research, rank tracking, backlinks) use the usage credits included with the plan, through the same endpoint. If you self-host, the software costs nothing and the Search Console tools use no paid data.

### Is it open source?

Yes. OpenSEO is open source under the MIT license, so you can [self-host](/docs/self-hosting) the whole thing, including the Search Console MCP. The software is free and Google doesn't charge for Search Console data. The keyword, rank and backlink tools need your own DataForSEO account, where the minimum top-up is $50. The one-click connection here uses OpenSEO's hosted Google app. If you self-host, you bring your own Google OAuth client, the same Cloud-console step the hosted version saves you.

### Is it read-only?

Yes. OpenSEO requests read-only access (`webmasters.readonly`). Your agent can read performance data and inspect URLs, but it can't change your account.

### Which AI clients work?

Any MCP client, including Claude Code, Claude Desktop, Cursor, Codex, and OpenClaw. Add the OpenSEO MCP endpoint and sign in.

### How fresh is the data?

It's Google's own data, so the most recent few days can be incomplete. History runs back 16 months, the same as the Search Console interface.
