# OpenSEO

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

> Semrush と Ahrefs に代わるオープンソースの選択肢

OpenSEO は_すべての人_のための SEO ツールです。Semrush や Ahrefs のようなツールが高価すぎたり、機能過多だったりする場合、OpenSEO は実際に自分で管理できる従量課金型の代替手段になります。

> あなたと AI エージェントのためのオールインワン SEO ツール。

Claude Code、OpenClaw、Hermes など、あらゆるエージェントと接続できます。あらかじめ用意されたスキルに加え、OpenSEO を自分のニーズに合わせるための独自スキルも作成できます。

## ホスト版

Web サイトで OpenSEO を無料で試せます。プロジェクトを支援したい場合、ホスト版のサブスクリプションは月額 10 ドルです。

[openseo.so](https://openseo.so)

## OpenSEO を使う理由

- クラス最高水準の MCP と AI スキル。
- モダンでシンプルな UI。
  - 肥大化した複雑な SEO スイートではなく、目的を絞ったワークフローを提供します。
- サブスクリプション不要。
  - 自分の DataForSEO API キーを使い、使用した分だけ支払います。
- Fork して、バイブコーディングで独自のカスタムツールを作れます。

## 主な SEO ワークフロー

- キーワード調査
- 順位追跡
- 競合分析
- バックリンク
- サイト監査
- AI 可視性

## OpenSEO MCP とエージェントスキル

OpenSEO は MCP サーバーを公開しており、Claude Code、OpenClaw、Hermes などの AI エージェントが SEO データを直接利用できます。エージェントスキルは、MCP を使った SEO タスクをエージェントに案内する再利用可能なワークフローです。

- [OpenSEO MCP を設定](https://openseo.so/docs/mcp)
- [OpenSEO エージェントスキルを設定](https://openseo.so/docs/skills/setup)

## セルフホスト

OpenSEO は二つのセルフホスト方法に対応しています。

- **シンプル：Docker** - 自分のマシンで個人利用する場合（最初に試す方法として推奨）。[`docs/SELF_HOSTING_DOCKER.md`](./docs/SELF_HOSTING_DOCKER.md) をご覧ください。
- **高度：Cloudflare** - インターネット公開、複数端末、またはチームでのセルフホスト向け（無料プランで利用可能）。[`docs/SELF_HOSTING_CLOUDFLARE.md`](./docs/SELF_HOSTING_CLOUDFLARE.md) をご覧ください。

どちらの方法でも、SEO データを取得するには DataForSEO API キーが必要です。[`docs/DATAFORSEO_API_KEY.md`](./docs/DATAFORSEO_API_KEY.md) をご覧ください。

## 費用

OpenSEO で SEO データを取得するには [DataForSEO](https://dataforseo.com/?aff=255379) API キーが必要です。セルフホストする場合は DataForSEO へ直接支払います。

[openseo.so/pricing](https://openseo.so/pricing) をご覧ください。

セルフホスト時の費用は、Web サイト上の見積もりより少し低くなります。ホストサービスは、DataForSEO に送信するリクエストごとに 28% を上乗せして収益を得ています。
