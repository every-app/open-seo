Mobile SERPs in MCP, rank tracking fixes, and clearer Search Console errors.

## What's new

- Check mobile results and organic rank with the `get_serp_results` MCP tool
- Shopify crawler signatures work past the homepage
  - Requires `CRAWLER_ACCESS_SECRET` (32+ characters), then save your signature again

## Fixed

- Incomplete rank checks no longer look like lost rankings.
- Claude no longer reports "no data" from MCP tools that returned results.
- Self-hosted site audits show start times in your timezone instead of UTC. — thanks @zigojacko2
- Search Console shows what to fix instead of "Connection expired" when a permission is missing or its API isn't enabled.
- The project switcher shows all your projects after you switch.
