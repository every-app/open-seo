Suggested searches on Keyword Research, and a fix for large site audit results.

## What's new

- Suggested searches on Keyword Research, from your site's topics and Search Console
  - Agents get them with the new `get_suggested_keywords` MCP tool

## Fixed

- Results of large site audits load instead of showing an error.
- Rank Tracking, Local SEO and Prompt Tracking checks no longer show as failed while they're still running.
- Updating the Docker edition no longer leaves the app down.
