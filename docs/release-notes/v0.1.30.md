Embed links for other dashboards, plus keyword, site audit and Docker fixes.

## What's new

- Embed a project's live rankings and Search Console data in other dashboards, like GoHighLevel
  - In Project settings → Integrations (self-hosted installs need `AUTH_MODE=password`)

## Fixed

- Keyword Research no longer shows keywords in title case.
- Site audits no longer analyze a "Checking your browser" page as if it were the site.
- In the Docker setup, a bad treg token or empty treg balance now says so instead of showing a confusing error.
