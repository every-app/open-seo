ChatGPT and Claude installs, IndexNow submissions, and rank trackers per language.

## What's new

- Add OpenSEO to ChatGPT or Claude with buttons on the dashboard — thanks @carterwsmith
- Submit changed pages to Bing and other IndexNow engines, in Settings → Integrations or with the `submit_indexnow_urls` MCP tool
  - Requires uploading a key file to your site
- Track the same site in more than one language
- Title and meta description length issues show the flagged text

## Fixed

- Keywords that have ranked before are no longer marked "Not found" after one bad Google results page.
- Prompt Research no longer suggests questions about a different meaning of your keyword.
- Website setup can read sites that block it, including Shopify stores, when `CONTEXT_API_KEY` is set.
- IndexNow submissions retry through Yandex or Yep when Bing won't take them — thanks @carterwsmith
- Active MCP connections no longer break and need reconnecting — thanks @carterwsmith
