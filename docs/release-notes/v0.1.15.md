Search Console and GA4 setup over MCP, rank-grid maps in `local-seo` reports, and a way to disconnect agents.

## What's new

- Pick a project's Search Console site and GA4 property with MCP tools — thanks @ChNirvik
- Reports from the `local-seo` skill show the rank grid on a Google Map
  - Requires `GOOGLE_MAPS_API_KEY`
- Disconnect MCP agents in Settings → Connected agents
- Interactive Search Console and search results views in MCP clients that support them

## Fixed

- Running "Check rankings" rechecks keywords that have never ranked instead of saving them as "Not found" again.
- Prompt Tracking lets you pick any country, and grays out engines that can't collect there.
- Connecting Claude Code to OpenSEO no longer gets stuck on "Authorizing...".
- Search Console's "Last 7 days" and "Last 28 days" totals no longer count an extra day. — thanks @caelum0x
- An unverified DataForSEO account now shows how to fix it instead of "Something went wrong". — thanks @VodouAI
