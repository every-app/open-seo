Website monitoring dashboard, Claude and Perplexity tracking, and faster Run now checks.

## What's new

- A dashboard for monitoring your saved website
  - Saving a website starts a site audit automatically
- Track Claude and Perplexity in Prompt Tracking
  - Their answers cost more than the other engines
- Run now in Prompt Tracking returns answers in minutes
- See the prompts behind each citation on the Citations tab
- Move tracked prompts between topics and rename topics
