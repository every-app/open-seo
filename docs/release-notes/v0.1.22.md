Docker fixes for Local SEO, long-running checks and Raspberry Pi 5.

## Fixed

- On Docker, Local SEO rank checks now run, and `GOOGLE_MAPS_API_KEY` in `.env` turns on the map.
- On Docker, large site audits, AI visibility runs and rank checks no longer freeze partway through.
- A stuck AI visibility or rank check run no longer blocks new checks.
- On a Raspberry Pi 5, Docker now explains how to fix the kernel setting it can't start on, instead of crashing with a cryptic error.
