Site audit fixes for Shopify stores, Chinese and Japanese pages, and sites behind Cloudflare.

## Fixed

- Site audits of Shopify stores no longer stop when Shopify refuses a single page.
- Chinese, Japanese and Thai articles are no longer wrongly flagged as thin content.
- Email links on sites behind Cloudflare are no longer reported as broken.
- An audit that finds no issues now says so instead of asking you to run it again.
- Scanning your site from the dashboard no longer fails on Docker installs without `CONTEXT_API_KEY`.
