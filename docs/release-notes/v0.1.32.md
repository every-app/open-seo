Branded query filter in GSC Insights, Local SEO in miles, and agent reports that lead with the plan.

## What's new

- Filter GSC Insights and the `get_search_console_performance` MCP tool by branded and non-branded queries
  - Google only classifies top-level properties with enough traffic; the filter is hidden on others
- Show Local SEO distances in miles
  - Switch units under Distances in Settings
- Reports from OpenSEO skills now open with a verdict and a short action plan
  - Update your OpenSEO skills to get it
- Use a treg token (`TREG_API_TOKEN`) instead of a DataForSEO key on Every App
  - Requires Every App Gateway 0.4.2 or later

## Fixed

- Site audits that a site blocks on every page, as many Shopify stores do, now show as Blocked instead of Done.
- Update keyword stats no longer fails on some older city rank trackers created by agents.
- Move to Every App now works from the standalone Docker setup.
