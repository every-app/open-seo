Keyword wildcards, redesigned Keyword Research and dashboard, and steadier rank checks.

## What's new

- Search keyword patterns with `*` wildcards, like `best * for dogs`
- Redesigned Keyword Research
- Redesigned the dashboard, with a Search Console chart
- Rank checks and SERP results read each keyword several times to get past unreliable Google results
  - Rank checks cost more and can take up to 2 hours
- Set a brand name for Prompt Tracking separately from the project name
- Serve a Cloudflare self-host from your own domain with `CUSTOM_DOMAIN` — thanks @pogorelschi, @clangille, @kalidiagne

## Fixed

- DataForSEO features work again on the Docker edition. — thanks @mangandini
- Saved AI visibility results open without an OpenRouter key.
- MCP clients stay connected after redeploying a Cloudflare self-host that uses Cloudflare Access.
- Dashboard chart lines no longer stop partway after changing the date range.
