OpenSEO 是一款面向_所有人_的 SEO 工具。如果 Semrush 或 Ahrefs 这类工具过于昂贵或臃肿，OpenSEO 是一款真正由你掌控的按量付费替代方案。

> 为你和你的 AI 智能体提供的一体化 SEO 工具。

可连接 Claude Code、OpenClaw 或 Hermes 等任意智能体。我们提供预构建技能，你也可以自行构建技能，根据自己的需求定制 OpenSEO。

- 一流的 MCP 和 AI 技能。

## OpenSEO MCP 与智能体技能

OpenSEO 提供 MCP 服务器，让 Claude Code、OpenClaw 和 Hermes 等 AI 智能体能够直接使用你的 SEO 数据。智能体技能是可复用的工作流，可指导智能体通过 MCP 完成 SEO 任务。

- [设置 OpenSEO MCP](https://openseo.so/docs/mcp)
- [设置 OpenSEO 智能体技能](https://openseo.so/docs/skills/setup)

## 自托管

OpenSEO 支持两种自托管方式：

- **简单方式：Docker**，适合在自己的机器上供个人使用（建议入门时采用）。请参阅 [`docs/SELF_HOSTING_DOCKER.md`](./docs/SELF_HOSTING_DOCKER.md)。
- **高级方式：Cloudflare**，适合面向互联网、跨多台设备或团队使用的自托管（免费套餐即可使用）。请参阅 [`docs/SELF_HOSTING_CLOUDFLARE.md`](./docs/SELF_HOSTING_CLOUDFLARE.md)。

无论采用哪种方式，都需要 DataForSEO API 密钥才能获取 SEO 数据。请参阅 [`docs/DATAFORSEO_API_KEY.md`](./docs/DATAFORSEO_API_KEY.md)。

## 成本

OpenSEO 需要 [DataForSEO](https://dataforseo.com/?aff=255379) API 密钥才能获取 SEO 数据。自托管时，你需要直接向他们付费。

请参阅 [openseo.so/pricing](https://openseo.so/pricing)

自托管时，你的成本会略低于我们网站上的估算值。托管服务的盈利方式是在我们向 DataForSEO 发起的每次请求上加收 28%。
