Saved reports, reusable report templates and Search Console filters.

## What's new

- Save reports from Claude Code, Codex and other MCP clients inside a project
  - Read them in the app or export to PDF
- Create reusable report templates per project
- Filter Search Console results by position and impressions through MCP
