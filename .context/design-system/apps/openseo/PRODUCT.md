# OpenSEO - Product Direction

## Register

product

## Naming status

`OpenSEO` is the current repository identity. The ByteDesk product rename is not
yet approved; do not invent or publish a replacement name from this profile.

## Purpose

OpenSEO is an agent-ready SEO marketing and analysis platform covering keyword
research, rank tracking, competitors, backlinks, site audits, and AI visibility.
It supports hosted and self-hosted use and exposes MCP and reusable agent skills.

## Users and promises

Marketers, builders, and agents need evidence-backed analysis, understandable data
costs, reproducible workflows, and a clear distinction between observed data,
derived recommendations, queued agent work, and unavailable provider results.

## Voice

Analytical, direct, and action-oriented. Never manufacture rankings, traffic,
costs, competitor facts, or agent activity.
