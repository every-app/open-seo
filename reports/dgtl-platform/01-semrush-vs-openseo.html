Verdict: extend the existing dashboard. OpenSEO already contains the foundations for your SEO dashboard and reports. DGTL needs to connect the workflows and add client controls, rather than build the platform from zero.

This comparison inspects code on dev-seo, commit 84e4705, package version 0.1.9. “Present” means implemented in source; it does not mean deployed or verified against your accounts.

Semrush reference

Semrush combines project widgets for traffic, Search Console, organic rankings, backlinks, and site monitoring. Widgets open detailed source reports, show setup actions when needed, and refresh at different cadences. GA4 can supply first-party traffic data; Semrush traffic estimates remain a different data source. Its backlink widget includes referring-domain trends and Authority Score distribution. The private project in your original link remained behind login, so these are documented product features, not verified settings of that project. Semrush dashboard guide.

The integrated dashboard you need

Use this navigation: Overview · Problems · SEO research · Web analytics · Behavior · Reports · Integrations. Keep the client organization and selected website visible on every page.

  • Overview: Search Console performance, GA4 traffic and key events, rank movement, audit issues, backlinks, and a Clarity behavior summary.
  • Problems: “What happened, which pages, what evidence, what action, who owns it, and was it fixed?” Each card opens a detailed problem report.
  • Reports: saved dated snapshots, with source links, comparisons and recommendations. Keep live metrics separate from the historical report version.

Problem report lifecycle

StepRequired behavior
DetectUse audit rules and configurable traffic/behavior thresholds. Apply minimum sample sizes.
ExplainStore website, URL, source, period, current/previous values, severity and confidence. Missing data is not zero.
InvestigateOpen the affected-page audit, GA4 detail, Search Console detail, or authenticated Clarity view.
Assign and actNew → In progress → Ready to verify. Record owner, recommendation and action date.
VerifyRe-crawl or compare a suitable post-change period; close as Resolved or Accepted risk. Preserve evidence.
ReportSave an immutable report snapshot and show it to authorized client members. Add explicit scheduled delivery later.

Example, hypothetical: a service page loses search clicks while organic sessions and lead events also fall. Present these as related observations on the same URL and dates; a broken CTA or rage-click signal is a hypothesis to investigate, not proof of the cause.
