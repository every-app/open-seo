Decisions the research resolves

  • Reuse and extend OpenSEO instead of restarting.
  • GA4 uses OAuth; a generic API key cannot read private property data.
  • Clarity summaries can be integrated; full native heatmap rendering is not supplied by the documented export API.
  • Each client needs a separate organization. Current invitations grant admin, so client roles must change.
